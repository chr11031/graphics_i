Demo: WebGL Clipping for Points At Infinity

Name: Dane Christensen
Date: 7/11/2026


Description

WebGL on select GPUs implements clipping using an approximation of infinity for points with "W" coordinate set to "0". This is usually not detectable, but can be seen if the inverse depth value stored in the "W" component of glFragCoord is used for rendering in the Fragment Shader. The point above is rendered not using a quad, but a triangle that is clipped far enough away above the view port, so as to look like a quadrilateral.
