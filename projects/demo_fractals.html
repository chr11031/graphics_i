Description

IFS fractals are represented by a group of 2D affine transformations that are used repeatedly on random input points for some number of iterations. At each iteration a given transformation has a probability of being applied the results of the point from the previous iteration. Principal among these is the Barnsley Fern, which is reproduced in the canvas above.
