For this project, you will implement the pieces of your software rasterizer relating to perspective division and perspective correct interpolation. You will also implement the Blinn-Phong shading model as seen on the left. This model makes use of a base "Ambient", as well as additive "Diffuse" and "Specular". Again Note that from an API point, you are free to mimic or deviate from the conventions used by WebGL. In particular, you will want to make sure to model the following details:

    Divide by "W":

    In your NDC step, it is important that you preserve "1/W" in the output "W" coordinate and that you divide all other interpolants by "W". Without this, perspective projection and perspective correct interpolation will not be implemented correctly.

    At the rasterization stage, make sure to use the "1/W" value to correct your interpolated attributed. Otherwise, your shader will give uncanny, linear-interpolation based results.

    Uniform data:

    This will be very similar to what you did for Project #2, except that you will need to support one more variable called "camera_pos". To implement this new feature, make sure that your uniforms structure takes in this new variable. As you can see both the Vertex and Fragment shader programs make use of the same UBO. This is related to the linking step that occurs between shaders. Effectively, all the different shaders may reference the same UBO for a particular struct as long as their definitions and precision standards match. Replicating this in your own pipeline should be a straightforward design to mimic.

    Blinn-Phong Shading:

    The shading model used in this project is a notable upgrade from the one in Project #2. Note in particular, that the shading has migrated from the Vertex Shader to the Fragment shader. Originally, Phong shading had all the same ideas as Blinn-Phong, but was susceptible to a particular failure mode in its implementation. Jim Blinn made a popular "fix" to this by introducing a vector called the "Half Vector", which is just the average of the light direction and eye direction vectors. By taking the dot product of the "Half Vector" and the Surface normal, the "Specular" component of this model is implemented.

    Make sure to take time to understand this model as it will appear again in the future/on an upcoming exam. As a very common/popular shading model, you should have a strong familiarity with it/feel comfortable implementing it from memory.
