For this project, you will implement several parts of your own software rasterizer. You will do this by extending the Javascript in this web page as well as in Software_Renderer.js. In the latter, you will add state and function calls to reproduce the functionality of WebGL using Javascript. The webGL version and your Software_Renderer will need to provide similar renderings of the teapots used in this template.

From an API point, you are free to mimic or deviate from the conventions used by WebGL. These act as a jump point for you to start reading what your Software Renderer will need to proivde an equivalence for:

    Global State:

  1. gl.enable - Important for allowing the CULL, SCISSOR, and DEPTH features used in a rasterizer.
  2. gl.clearColor - Sets the value for when the screen is eventually reset to a new color. Used here for a background color effect.
  3. gl.clear - For all flags passed in the respective buffers are cleared. Often used to clear color and depth values.

    4. VBO/UBO:

  4. gl.createBuffer - Allocates a new buffer (VBO, UBO, etc) and returns a handle to that object. At this point, no type is ascribed to that buffer object.
  5. gl.bindBuffer - Set a type to a given buffer and references this object for any subsequent and related buffer object function calls.
  6. gl.bufferData - Either allocate a bound buffer's memory or copy an array into buffer memory.
  7. gl.bufferSubData - Similar to gl.bufferData, but only modifies a subset of the buffer rather than allocating new memory or overwriting all members in the buffer.

    8. VAO:

  8. gl.createVertexArray - Allocate a new VAO (Vertex Array Object). The VAO will reference other VBOs to setup the input layout for a draw call such as "drawArrays".
  9. gl.bindVertexArray - Set the VAO as the current, in scope object for all subsequent VAO based function calls.
  10. gl.enableVertexAttribArray - Tell the bound VAO that a particular attribute is "enabled" for the "pipeline_input_assembler" reference internally.
  11. gl.vertexAttribPointer - Tell the bound VAO what index, how large, what the spacing is for a particular vertex attribute.

    12. UBO:

  12. gl.getUniformBlockIndex - Finds the block index of a uniform block within a shader program.
  13. gl.getActiveUniformBlockParameter - Used to query information about a Uniform Block in a shader, such as its total byte size (including padding).
  14. gl.bindBufferBase - Bind a UBO to a block binding slot.
  15. gl.uniformBlockBinding - Map a shader program (vertex + fragment)'s uniform block with a block binding slot.
  16. gl.getUniformIndices - From a linked shader program, find the unique uniform index of any given uniform variable.
  17. gl.getActiveUniforms - Query information about uniform variables such as the byte offset of a member from the beginning of its block ("gl.UNIFORM_OFFSET").

    18. Shader Program:

  18. gl.useProgram - Binds an already built GLSL program (vertex + fragment shaders) so any uniform/draw calls reference it.

    19. Drawing:

  19. gl.viewport - Changes the viewport transform used at the end of rasterization to a subset of the total target area. This affects rasterization outputs but not functions like gl.clear(...)
  20. gl.scissor - Restricts pixel operations including "gl.clear(...)" to a subset of the total target area.
  21. gl.drawArrays - The essential draw function used to render the teapot. Draws triangles to render the teapot above.
